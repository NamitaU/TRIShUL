TRIShUL

Technique for Reconstructing magnetic Interstellar Structure Using starLight polarization

TRIShUL is a fast, frequentist-based framework for decomposing line-of-sight (LOS) stellar polarization as a function of distance. The method identifies the number of dust clouds along the LOS and computes their mean polarization properties. These results can be used to reconstruct three-dimensional (3D) plane-of-sky (POS) magnetic structures in the interstellar medium (ISM).
