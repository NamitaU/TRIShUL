TRIShUL

Technique for Reconstructing magnetic Interstellar Structure Using starLight polarization


References:

Uppal., N., et al., 2025, Accepted in A&A [https://ui.adsabs.harvard.edu/abs/2025arXiv251025911U/abstract]

This method decompose line-of-sight (LOS) stellar polarization as a function of distance and identifies the number of dust clouds
along the LOS and computes their mean polarization properties. 
This will be use to reconstruct three dimensional (3D) plane-of-sky (POS) magnetic structures in the interstellar medium (ISM).

It is fast and frequentist based framework

To run the code, the data structure should be same as presented in the sample.csv file.
